# 배드민턴 스코어보드

태블릿 크롬에서 쓰는 독립 점수판입니다. Rally Lab(분석기)과 코드·배포가 완전히 분리되어 있고, 서버 없이 정적 파일만으로 동작합니다.

## 조작

| 조작 | 동작 |
|---|---|
| 팀 영역 탭 또는 위로 쓸기 | 그 팀 +1 |
| 팀 영역 아래로 쓸기 | 그 팀의 이번 게임 최근 득점 1개 취소 (설정 "쓸기 방향 반대로"로 위·아래 바꾸기) |
| 화면을 왼쪽/오른쪽으로 쓸기 | 배경 색상 세트 바꾸기(사진 필터 고르듯 다음/이전 세트가 밀려 들어옴, 고른 세트는 저장) |
| 리모컨 한 번 / 두 번 / 길게(기본 0.7초) | 우리 팀 +1 / 상대 팀 +1 / 방금 입력 되돌리기. 누르는 동안 반복 입력은 한 번으로 묶음 |
| 되돌리기 / 코트 교대 | 양 팀 통틀어 마지막 입력 취소 / 좌우 교환(팀 기록은 유지) |

- 모든 득점·취소는 입력 즉시 이 기기(localStorage)에 시간순으로 저장되고, 새로고침 후 이어서 진행합니다. 기록 화면에서 CSV/JSON으로 내보낼 수 있습니다.
- 리모컨 화면에서 수신 키(key/code/repeat/간격)를 확인하고 버튼을 등록합니다. 볼륨 키는 크롬이 웹페이지에 전달하지 않을 수 있습니다.
- 서버 동기화(다른 기기에서 기록 보기)는 아직 없습니다. 이벤트마다 고유 ID를 저장해 두어 이후 중복 없는 동기화에 쓸 수 있습니다.

## AI 포즈 스코어링 (베타)

설정 → AI 포즈 스코어링 → **켜고 테스트**. 전면 카메라가 한쪽 팀을 보도록 세워 두고 씁니다.

| 동작 (설정한 시간만큼 유지) | 결과 |
|---|---|
| 머리 위로 두 팔을 모아 큰 **O** | 카메라 쪽 팀 +1 |
| 한 손은 머리 위, 다른 손은 아래 ("아쉬움") 또는 팔을 교차한 큰 **X** | 상대 팀 +1 |
| 두 팔을 옆으로 쭉 뻗은 **T** ("Time!") | 방금 입력 되돌리기 |

- 테스트 화면에서는 카메라 영상과 상체·팔 관절을 보여 주고, O를 인식하면 "AI 포즈 스코어링 기능 확인"을 띄웁니다. 테스트한 사람이 화면 왼쪽/오른쪽 중 어디에 섰는지로 카메라 쪽 팀을 정하고, 첫 득점 전이면 그 팀을 첫 서브로 정합니다(틀리면 "반대쪽 팀이에요").
- 경기 중에는 카메라 영상을 보이지 않고, 동작을 유지하는 동안 화면 전체가 점수를 받을 팀 색(되돌리기는 흰색)으로 물들고 인식되면 알림이 뜹니다. 두 명(복식) 중 누가 해도 됩니다.
- 테스트할 때 그 사람의 몸 크기를 기억해 두고, 경기 중에는 그보다 훨씬 작게(약 55% 미만) 보이는 사람, 예를 들어 옆 코트 사람은 무시합니다.
- 모델은 MediaPipe Pose Landmarker lite(약 5.8MB)이고 `public/vendor/mediapipe`에 함께 배포되어 오프라인에서도 동작합니다. 영상은 기기 안에서만 처리되고 저장·전송되지 않습니다.

## 배포 (Cloudflare Workers, 새 Worker `badminton-scoreboard`)

```powershell
cd scoreboard
npm ci
npx wrangler login
npm run deploy
```

처음 배포하면 `https://badminton-scoreboard.<계정 서브도메인>.workers.dev` 주소가 만들어집니다. 기존 `rally-lab`, `robot` Worker는 건드리지 않습니다.

Git 자동 배포를 원하면 Cloudflare 대시보드에서 새 Worker를 이 저장소에 연결하고 **Root directory를 `/scoreboard`**, Deploy command를 `npx wrangler deploy`로 지정합니다.

## 테스트

```powershell
npm test                                         # 규칙·취소·리모컨·포즈 동작 판정
python -m http.server 8811 --directory public    # 다른 창에서
node tests/ui.mjs                                # 브라우저 조작(Playwright 필요)
```

## 파일

- `public/core.js` — 경기 규칙. 점수는 저장하지 않고 이벤트 기록에서 매번 다시 계산합니다.
- `public/remote.js` — 리모컨 짧게/길게 판정과 반복 입력 묶기.
- `public/app.js` — 화면, 터치, 저장, 기록·설정 창, AI 포즈 테스트 화면.
- `public/pose.js` — 관절 좌표로 O/X 동작 판정과 유지 시간 판정(카메라 없이 테스트됨).
- `public/pose-camera.js` — 전면 카메라와 포즈 모델 실행(켤 때만 불러옴).
