# Cloudflare 배포

웹 화면: https://rally-lab.hngjuneui.workers.dev

2026-09-15: 사용자 승인 후 PC 임시 Cloudflare Tunnel 연결 및 재배포 완료. 공개 주소에서 로그인, 가상 카메라 분석 왕복, 영상 업로드·재생, 하이라이트 다운로드 테스트를 통과했습니다. 소스 저장 위치는 `hngjuneui/srh` 저장소의 `rally-lab/` 폴더입니다. PC 또는 터널 종료 시 원격 분석은 중단됩니다.

## 다른 네트워크에서 모바일 테스트

같은 Wi-Fi일 필요가 없습니다. PC는 유선 인터넷, 휴대폰은 LTE/5G여도 됩니다. 현재 PC 외부 연결은 구성되어 있습니다. 재시작 후에는 아래 순서로 다시 연결합니다.

1. PC에서 `./start.ps1`로 분석 서버를 실행하고 절전 상태로 들어가지 않도록 합니다.
2. 공개 연결을 승인한 뒤 Cloudflare Tunnel을 PC의 `http://127.0.0.1:8765`에 연결합니다. 이 과정은 공유기 포트 포워딩 없이 PC에서 외부로 연결을 만듭니다.
3. 터널의 HTTPS 주소를 Worker의 `BACKEND_URL`에 설정합니다. 아래 재배포 명령을 사용합니다. 임시 터널 주소는 재시작 때 변경될 수 있습니다.
4. 휴대폰에서 Wi-Fi를 끄고 LTE/5G로 공개 웹 주소를 엽니다. PC 실행 창의 8자리 코드로 로그인합니다. 코드 파일은 `data/access-code.txt`이며 GitHub에 포함하지 않습니다.
5. 카메라 권한을 허용하고 먼저 절약 전송 설정으로 짧게 시험합니다. PC 분석 프레임과 왕복 지연이 갱신되는지 확인합니다. 영상 파일 시험은 89 MiB 이하의 짧은 파일로 시작합니다.
6. PC에서 휴대폰과 같은 경기 주소를 열면 수신 상태를 확인할 수 있습니다. PC 화면에서는 카메라를 추가로 켜지 않습니다. 분석하는 동안 PC 서버와 터널을 모두 유지합니다.

휴대폰에서 `127.0.0.1:8765`를 입력하면 PC가 아니라 휴대폰 자신에게 연결하므로 사용할 수 없습니다. GitHub에 소스를 올리는 것만으로 PC 원격 연결이 생기지는 않습니다.

## 구조

휴대폰 HTTPS → Cloudflare Worker → HTTPS Tunnel → PC FastAPI(127.0.0.1:8765).

Worker는 `web/`만 정적 배포하고 `/api/*`, `/ws/*`를 지정된 PC 주소로 중계합니다. 분석 모델과 영상은 PC에 남습니다. Cloudflare는 전송 경로에서 영상 데이터를 처리하므로 완전한 로컬 전용 처리는 아닙니다. PC와 터널이 꺼지면 분석은 중단되지만 웹 화면은 열립니다.

PC 공개 연결에는 별도의 사용자 승인이 필요합니다. 8자리 연결 코드를 아는 사용자는 이 프로토타입의 전체 경기/영상 데이터에 접근할 수 있습니다. 개인 테스트용이며 계정별 데이터 격리나 운영용 접근 제어는 아직 없습니다. 연결 코드를 공개 저장소나 화면 캡처에 포함하지 마세요.

## 배포/검증 명령

```powershell
npm ci
npx wrangler login
npx wrangler types
npm run check:worker
npm run test:worker
npx wrangler deploy --dry-run
npm run deploy
```

PC 공개 연결 승인 및 HTTPS 터널 구성 후, 실제 터널 주소를 변수로 지정해 배포합니다. 소스의 기본 주소는 비어 있으며 `npm run deploy`는 원격 변수 값을 보존합니다.

```powershell
npx wrangler deploy --var BACKEND_URL:https://YOUR-PC-TUNNEL-HOST
```

현재 외부 업로드는 파일당 89 MiB로 제한합니다. 로컬 서버의 512 MiB 제한보다 작으며, 큰 영상은 짧게 나눠 시험하세요. 터널 업로드 한도, 통신사 속도와 PC 처리 속도의 영향을 받습니다. 임시 터널을 사용하면 재시작 시 주소가 달라져 `BACKEND_URL`을 갱신해야 합니다.

외부 연결 후 `RALLY_BASE_URL`을 공개 주소로 설정하고 `node tests/browser.mjs`로 로그인, 가상 카메라 왕복, 업로드, 점수 수정 및 모바일 레이아웃을 검사할 수 있습니다. 이 테스트는 새 테스트 경기를 생성하며 기존 경기를 수정하지 않습니다. 실제 휴대폰 통신사망 검증은 별도입니다.

GitHub Pages는 Python 분석 서버를 실행하지 않습니다. 이 프로젝트는 GitHub에 소스를 보관하고 Cloudflare에서 웹 화면을 제공하는 구성입니다. 기존 저장소의 사이트 배포 설정은 변경하지 않습니다.
